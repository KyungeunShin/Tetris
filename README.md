# Tetris MVP 실행 To-Do

[PRD.md](./PRD.md)를 기준으로 브라우저에서 설치나 로그인 없이 플레이하는 싱글 플레이어 테트리스를 구현한다. 아래 표는 의존성을 고려한 구현 순서이며, 각 작업의 선행 Task를 명시한다. 구현 작업마다 해당 동작을 검증하는 테스트를 함께 완료한다. 게임 로직 테스트는 DOM이나 실제 시간에 의존하지 않도록 작성한다.

## 실행 방법

이 프로젝트는 순수 HTML/CSS/JavaScript로 구성하며 프레임워크나 빌드 도구를 사용하지 않는다. 의존성 설치나 개발 서버 실행 없이 프로젝트 폴더의 `index.html`을 더블클릭하면 기본 브라우저에서 열린다. 세 파일(`index.html`, `style.css`, `script.js`)은 같은 폴더에 둔다.

현재는 7종 블록이 무작위로 상단 중앙에 생성된다. NEXT 영역에서 다음 블록을 미리 확인할 수 있으며, 고정 후 미리보기의 블록이 실제 활성 블록이 되고 새로운 미리보기가 생성된다. 레벨은 1부터 시작하며 누적 점수 1,000점마다 1씩 오른다. 자동 하강 간격은 500ms에서 레벨마다 40ms씩 줄고 최소 100ms를 유지한다(레벨 1: 500ms, 레벨 2: 460ms, 레벨 3: 420ms). 하강이 막히면 현재 위치에 고정한 뒤 완성된 줄을 동시에 제거하고 위의 행들을 내려 빈 공간을 채운다. 한 번에 지운 1/2/3/4줄에 따라 100/300/500/800점을 누적하며 우측 점수 영역에 즉시 표시한다. 줄 제거 후 미리 보관한 다음 블록으로 교체하고, 생성 위치가 막히면 ‘게임오버’ 안내와 함께 타이머를 멈추고 조작을 차단한다. 우측 ‘다시시작’ 버튼은 진행 중이나 종료 후 언제든 빈 보드·0점·레벨 1·새 블록과 미리보기로 초기화하고 자동 하강을 다시 시작한다. 연속 클릭해도 낙하 타이머와 키 입력 처리는 중복되지 않는다.

화면 너비에 맞춰 보드 캔버스의 1:2 비율을 유지하며 축소한다. 600px 이하에서는 NEXT와 점수·레벨 패널을 보드 아래에 배치한다. 모바일 화면에서도 표시되며 조작은 키보드를 사용한다.

### 키보드 조작

- ← / →: 한 칸 이동. 길게 누르면 반복 이동한다.
- ↓: 한 칸 빠른 낙하(Soft Drop). 길게 누르면 반복 하강하며 막히면 고정한다.
- ↑: 시계 방향 90도 회전. 모양 행렬의 왼쪽 위 좌표를 유지하고 벽·바닥·고정 블록과 충돌하면 회전을 취소한다.
- Space: 가능한 가장 아래 위치로 즉시 하강(Hard Drop)하고 고정한다. 한 번 누를 때 한 블록을 고정하며 길게 눌러도 연속 고정하지 않는다.

조작키 입력 시 페이지 스크롤을 방지하며 Game Over 후에는 조작이 차단된다.

## 현재 구현 검증

Node.js가 설치된 환경에서는 프로젝트 폴더에서 `node --test tests/*.test.cjs`를 실행한다. 게임 로직은 DOM 없이 검사하며 화면 연결은 캔버스와 타이머 대역으로 검사하므로 실제 시간을 기다리지 않는다. 7종 생성·회전, 경계와 고정 블록 충돌, 고정·재생성, Soft Drop·Hard Drop, 키 입력, 생성 충돌과 종료 시 타이머 중지를 검증한다. 줄 제거 테스트는 0~4줄 및 비연속 행 제거, 남은 행의 순서·보드 크기 보존, 점수 누적, 줄 제거 후 생성 판정, 자동 하강·Soft Drop·Hard Drop 후 점수 표시를 검증한다. 실제 브라우저 화면은 index.html을 열어 확인한다.

재시작 테스트는 7종 블록의 생성 충돌 및 종료 후 상태 보존, 진행 중·종료 후 보드와 점수 초기화, 종료 안내 및 타이머 중지, 버튼 연속 클릭 후 단일 타이머 유지와 키 입력 재개를 검증한다.

2026-10-06 검증: Node.js에서 72개 테스트가 모두 통과했다. 추가 테스트는 7종 미리보기와 실제 생성 블록의 일치, 미리보기 독립성, 레벨 경계와 최소 낙하 간격, 자동 하강·Soft Drop·Hard Drop의 레벨 상승 및 단일 타이머 갱신, 재시작 시 미리보기·레벨·속도 초기화를 검증한다. 실제 Chrome 헤드리스에서 280/320/375/600/601/768/1280px 너비의 가로 넘침 없음과 보드·미리보기 비율을 확인했다. 키보드 Hard Drop, Game Over, Restart가 정상 동작했고 JavaScript 실행 오류가 없었다. 375px 화면 캡처도 육안 확인했다. Edge·Firefox 및 실제 모바일 기기 검증은 미수행이다.

## 구현 작업

PRD에 없는 세부 규칙은 다음을 MVP의 초기 구현안으로 사용한다: 방향키 좌우 이동, 위쪽 방향키 시계 방향 회전, 아래쪽 방향키 Soft Drop, 초기 자동 하강 간격 0.5초(1,000점마다 레벨 상승, 레벨당 40ms 단축, 최소 100ms), 하강 불가 시 즉시 고정, 회전 충돌 시 회전 취소, 생성 위치가 막히면 Game Over. 한 번에 제거한 1/2/3/4줄의 점수는 100/300/500/800점이며 Soft Drop 추가 점수는 없다. 이는 PRD의 명시 요구사항이 아니라 구현과 테스트의 기준을 구체화한 선택이다.
