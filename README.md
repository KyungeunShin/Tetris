# Tetris

설치나 로그인 없이 브라우저에서 즐기는 싱글 플레이어 테트리스입니다. 내려오는 블록을 이동하고 회전해 가로줄을 채우고, 더 높은 점수에 도전해 보세요.

## 데모

**GitHub Pages 데모:** [테트리스 플레이하기](https://kyungeunshin.github.io/Tetris/)

## 게임 소개

- 10열 × 20행 보드와 7종 블록(I, O, T, S, Z, J, L)
- 다음 블록 미리보기(NEXT)와 점수·레벨 표시
- 자동 낙하, 줄 제거, 게임오버 및 다시시작
- 화면 너비에 맞춰 조정되는 반응형 화면

가로줄을 빈칸 없이 채우면 해당 줄이 사라지고 위의 블록이 내려옵니다. 새 블록이 생성될 공간이 없으면 게임이 끝납니다.

## 실행 방법

1. 프로젝트를 내려받습니다.
2. `index.html`을 더블클릭해 브라우저에서 엽니다.
3. 방향키와 스페이스로 플레이합니다.

`index.html`, `style.css`, `script.js`는 같은 폴더에 두세요. 게임 실행에는 의존성 설치, 개발 서버, 빌드 과정이 필요하지 않습니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| ← / → | 블록을 왼쪽 / 오른쪽으로 한 칸 이동 |
| ↑ | 블록을 시계 방향으로 90도 회전 |
| ↓ | 블록을 한 칸 빠르게 내리기(Soft Drop) |
| 스페이스(Space) | 블록을 가능한 가장 아래로 즉시 내리고 고정하기(Hard Drop) |

- ←, →, ↓는 길게 누르면 반복 동작합니다.
- 스페이스는 한 번 누를 때 블록 하나를 고정합니다.
- 회전 후 벽·바닥·고정된 블록과 겹치면 회전이 취소됩니다.
- 게임 중이나 게임오버 후 **다시시작** 버튼을 누르면 빈 보드, 0점, 레벨 1로 새 게임을 시작합니다.
- 모바일 화면에서도 표시되며, 조작에는 키보드가 필요합니다.

## 점수와 레벨

| 한 번에 제거한 줄 | 획득 점수 |
| --- | ---: |
| 1줄 | 100점 |
| 2줄 | 300점 |
| 3줄 | 500점 |
| 4줄 | 800점 |

레벨은 1부터 시작하며 누적 점수 1,000점마다 1씩 올라갑니다. 자동 낙하 간격은 처음 500ms이며, 레벨마다 40ms씩 줄어 최소 100ms까지 빨라집니다. Soft Drop과 Hard Drop에는 추가 점수가 없습니다.

## 릴리즈 정보

현재 제공되는 버전은 **MVP**이며, 정식 버전 번호와 Git 릴리즈 태그는 아직 지정되지 않았습니다.

| 항목 | 내용 |
| --- | --- |
| 구현 기능 | 이동·회전, 자동 낙하, Soft Drop·Hard Drop, 줄 제거·점수 계산 |
| 편의 기능 | 다음 블록 미리보기, 레벨별 속도 증가, 게임오버 안내, 다시시작 |
| 화면 | 데스크톱 및 좁은 화면에 대응하는 반응형 레이아웃 |
| 기술 구성 | HTML, CSS, JavaScript — 프레임워크 및 빌드 도구 없음 |

현재 버전에는 Hold, Ghost Piece, 모바일 터치 조작, 사운드, 온라인 멀티플레이 및 랭킹 서버가 포함되어 있지 않습니다.

## 테스트

Node.js가 설치되어 있다면 프로젝트 폴더에서 다음 명령을 실행할 수 있습니다.

```sh
node --test tests/*.test.cjs
```

게임 로직과 입력 처리, 줄 제거·점수 계산, 게임오버·재시작, 다음 블록 및 레벨 변경을 검사합니다. 실제 화면과 키보드 동작은 `index.html`을 브라우저에서 열어 확인할 수 있습니다.
