# 시나리오 플레이 테스트

PRD.md와 README.md의 현재 규칙 및 실행법을 확인한 뒤 실제 브라우저에서 시나리오를 수행한다. 코드를 직접 수정하지 않는다. 재현용 상태는 기존 테스트·디버그 수단으로만 준비하고 제품 코드에 테스트 우회를 추가하지 않는다.

## 점검 체크리스트

- [ ] 첫 진입
  - 통과: 설치·로그인 요구 없이 10 × 20 보드, 첫 블록, 0점으로 플레이가 시작된다. 실패: 진입 오류나 잘못된 초기 상태가 보인다.
- [ ] 자동 하강과 Soft Drop
  - 통과: 정의된 간격으로 하강하고 아래쪽 방향키로 즉시 한 칸 하강을 시도한다. 실패: 멈춤·중복 하강·입력 무응답이 발생한다.
- [ ] 이동과 회전
  - 통과: 좌우·회전 입력이 반영되고 벽이나 고정 블록을 통과하지 않는다. 실패: 잘못된 위치·형태·화면 잔상이 발생한다.
- [ ] 바닥과 블록 위 고정
  - 통과: 마지막 유효 위치에 고정되고 다음 블록이 한 번 생성된다. 실패: 블록 겹침·위치 오차·중복 생성이 발생한다.
- [ ] 라인 제거와 점수
  - 통과: 한 번에 1/2/3/4줄 제거 시 각각 100/300/500/800점이 증가하고 남은 행이 올바르게 내려온다. 실패: 제거 수·행 순서·점수 중 하나라도 다르다.
- [ ] Game Over
  - 통과: 다음 생성 위치가 막히면 종료 안내가 표시되고 입력·시간 경과로 상태가 변하지 않는다. 실패: 종료 누락이나 종료 후 플레이가 발생한다.
- [ ] 종료 후 및 진행 중 Restart
  - 통과: 두 상태에서 재시작하면 빈 보드·0점·새 블록으로 복귀하고 자동 하강이 한 번씩 실행된다. 실패: 이전 상태나 중복 타이머가 남는다.
- [ ] 반복 플레이와 브라우저
  - 통과: 연속 재시작 및 README의 지원 데스크톱 브라우저에서 조작이 정상이며 콘솔 오류가 없다. 실패: 반복 실행이나 특정 지원 브라우저에서 재현 가능한 오류가 발생한다.

## 보고

시나리오별 브라우저, 준비 상태, 입력 순서, 기대·실제 결과, 판정과 증거를 기록한다. 수행하지 못한 시나리오는 미검증으로 표시한다. 점수 등의 적용 규칙이 변경되었다면 문서의 명시 규칙을 우선하고 차이를 기록한다.

문제는 아래 표로 보고한다. 높음은 진행·종료·재시작 불가 또는 상태 훼손, 중간은 일부 조작·점수·화면 오류, 낮음은 플레이를 막지 않는 표시 문제다. 문제가 없으면 없다고 명시한다.
