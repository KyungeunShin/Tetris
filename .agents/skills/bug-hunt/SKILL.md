# 집중 버그 탐지

PRD.md, README.md, 기존 테스트와 변경 내용을 읽고 위험이 큰 상태 전이부터 조사한다. 코드를 직접 수정하지 않는다. 추정과 재현한 결함을 구분하고 영향·빈도·재현 조건을 근거로 우선순위를 정한다.

## 점검 체크리스트

- [ ] 타이머와 이벤트 중복
  - 통과: 반복 초기화·Restart 후에도 입력과 자동 하강이 한 번씩 처리된다. 실패: 콜백 중복이나 이전 게임의 콜백이 새 상태를 변경한다.
- [ ] 하강 경합
  - 통과: 자동 하강과 Soft Drop이 근접해 발생해도 각 동작이 유효 상태에 적용되고 중복 고정·생성이 없다. 실패: 상태 전이가 두 번 실행되거나 블록이 유실된다.
- [ ] 보드 및 형태 데이터 훼손
  - 통과: 생성·회전·행 제거·Restart가 다른 행이나 원본 형태를 의도치 않게 바꾸지 않는다. 실패: 참조 공유나 범위 밖 쓰기로 상태가 훼손된다.
- [ ] 다중 행 제거와 누적 점수
  - 통과: 연속·비연속 완성 행이 동시에 제거되고 한 번만 점수가 반영된다. 실패: 행을 건너뛰거나 점수가 누락·중복된다.
- [ ] 종료와 재시작 경계
  - 통과: 종료 뒤 동작이 차단되고 재시작 뒤 이전 상태·예약 작업이 남지 않는다. 실패: 종료 후 변경이나 재시작 후 즉시 오작동이 발생한다.
- [ ] 오류 경로와 재현성
  - 통과: 의심 사례의 실행 오류·콘솔 오류를 확인하고 동일 조건에서 결과를 재현할 수 있다. 실패: 예외로 게임이 중단되거나 결함 주장에 재현·코드 근거가 없다.

## 보고

체크별 판정과 근거를 기록하고 미검증을 통과로 처리하지 않는다. 재현한 문제에는 준비 상태, 입력 순서, 기대·실제 결과, 파일·위치를 붙인다. 미재현 의심은 별도로 표시한다.

아래 표를 심각도 내림차순으로 정렬한다. 높음은 게임 중단·데이터 훼손·재시작 불가, 중간은 제한된 조건의 기능 오류, 낮음은 비핵심 표시·검증 문제다. 같은 심각도에서는 발생 빈도와 영향 범위가 큰 문제를 먼저 제시한다. 문제가 없으면 없다고 명시한다.
