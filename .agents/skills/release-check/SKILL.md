# 릴리스 점검

PRD.md와 README.md, 진입 HTML, 자산 경로, 빌드 설정, 배포 워크플로를 확인한다. 코드를 직접 수정하지 않으며 push·설정 변경·배포를 수행하지 않는다. GitHub 설정은 접근 가능한 읽기 전용 정보로 확인하고 없으면 미검증으로 보고한다. 최신 GitHub Pages 동작을 확인해야 할 때는 공식 문서를 조회한다.

## 점검 체크리스트

- [ ] 파일 연결과 대소문자
  - 통과: HTML·CSS·JS·자산 참조가 실제 파일의 경로·대소문자와 일치한다. 실패: 누락·경로 오타로 파일 로드가 실패한다.
- [ ] 프로젝트 하위 경로
  - 통과: GitHub Pages의 실제 기본 경로 아래에서 모듈·자산이 로드된다. 실패: 루트 절대 경로나 잘못된 base 설정으로 404가 발생한다.
- [ ] 실행·빌드·테스트 안내
  - 통과: README에 실제 선행 조건과 명령이 있고 재현 실행 및 필수 테스트가 성공한다. 실패: 누락된 명령·설정 또는 실행 실패가 있다.
- [ ] 배포 산출물
  - 통과: 사용 방식에 맞는 진입 index.html과 필요한 자산이 게시 폴더 또는 빌드 결과에 포함된다. 실패: 소스만 게시되거나 진입점·의존 파일이 빠진다.
- [ ] GitHub Pages 게시 설정
  - 통과: 브랜치·폴더 게시 또는 Actions 방식이 산출물 위치와 일치하며 선택한 방식의 필수 설정을 충족한다. 실패: 게시 원본 불일치 또는 워크플로의 필수 권한·업로드·배포 단계 누락이 있다.
- [ ] 게시 페이지 동작
  - 통과: 게시 URL에서 자산 오류 없이 게임을 시작·조작·종료·Restart할 수 있다. 실패: 로드 오류나 핵심 시나리오 회귀가 발생한다.
- [ ] MVP 릴리스 근거
  - 통과: PRD 성공 기준과 관련 테스트·플레이 결과가 확인되고 높은 심각도 문제가 없다. 실패: 성공 기준 미충족이나 높은 심각도 결함이 남는다.

## 보고

체크별 판정, 명령·URL·파일·설정 근거를 기록한다. 미배포 상태의 게시 URL 확인 등 수행할 수 없는 항목은 미검증과 이유를 표시하고 릴리스 준비 여부를 확정하지 않는다.

문제는 아래 표로 보고한다. 높음은 게시·게임 실행 불가 또는 핵심 기능 실패, 중간은 재현 안내·지원 환경·설정 검증 부족, 낮음은 동작에 영향 없는 문서 오류다. 문제가 없으면 없다고 명시한다.
